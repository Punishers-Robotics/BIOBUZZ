# Evidence assets for Markdown records

Keep original approved photos, diagrams, plots, and small evidence files here.
Create a subject subfolder when adding an asset, for example
`mechanical\2026-11-22-intake-test.jpg` or
`outreach\2026-11-22-workshop-summary.csv`.
These are naming examples, not existing evidence.

Use descriptive dated filenames. Link each asset from a Markdown record and
explain its date, creator or source, what it shows, and publication permission.
From a mechanical record, use a relative link such as
`[Test photo](../assets/mechanical/2026-11-22-intake-test.jpg)`.

Only upload material the team is allowed to publish. Do not include unapproved
identifiable people, personal contact details, raw participant lists, secrets,
or confidential information. Use aggregated data where appropriate.
For large videos or data sets, link an approved storage location instead of
committing large files to Git.

Portfolio publishing assets are separate under `portfolio\assets`.
Copy only selected approved images there, retaining the original evidence here
and linking its source record from the portfolio content.
